# Дневник настроения

Личный дневник настроения: один боб на каждый день. Работает офлайн, без аккаунтов и без сервера. Все данные лежат в IndexedDB на самом устройстве.

## Как поставить на iPhone или iPad

PWA нельзя установить из файлов на диске — нужен адрес по HTTPS. Порядок такой:

1. Выложи содержимое папки на любой статический хостинг: GitHub Pages, Netlify Drop (перетаскиванием), Vercel, Cloudflare Pages.
2. Открой полученный адрес в **Safari** (Chrome на iOS не умеет добавлять PWA).
3. Кнопка «Поделиться» → «На экран „Домой“».
4. Запусти приложение с иконки — оно откроется без адресной строки.
5. Один раз загрузи его при интернете. Дальше работает офлайн.

### Проверить локально

```bash
cd mood
python3 -m http.server 8080
```

Затем открыть `http://localhost:8080`. Сервис-воркер на `localhost` работает, на `file://` — нет.

## Данные

- Хранилище: IndexedDB, база `mood-diary`, версия 1.
- Хранилища: `entries` (ключ — дата `YYYY-MM-DD`) и `settings` (ключ — имя настройки).
- Если IndexedDB недоступна, приложение само переходит на localStorage и пишет об этом в настройках.
- Дата считается по локальному часовому поясу устройства, без UTC-сдвигов.

Запись дня:

```json
{
  "date": "2026-08-13",
  "mood": 4,
  "weather": "rainy",
  "dayType": "work",
  "comment": "Хороший день",
  "updatedAt": 1786578442665
}
```

`mood`: 5 — отлично, 4 — хорошо, 3 — нормально, 2 — плохо, 1 — ужасно.
`weather`: `sunny` | `cloudy` | `rainy` | `snowy` | `windy`.
`dayType`: `work` | `rest` | `both`.

### Резервная копия

Настройки → «Экспортировать данные» отдаёт JSON со всеми записями и цветами. «Импортировать данные» загружает его обратно: записи с совпадающими датами перезаписываются, остальные добавляются.

**Важно:** если удалить приложение с экрана «Домой» или очистить данные Safari, дневник исчезнет вместе с ними. Делай экспорт раз в пару месяцев.

## Структура

```
index.html               разметка всех экранов
manifest.webmanifest     манифест PWA
service-worker.js        офлайн-кэш
css/style.css            стили
js/db.js                 IndexedDB + запасное хранилище, экспорт/импорт
js/beans.js              SVG-бобы: пять выражений, цвет отдельно
js/icons.js              иконки интерфейса, погоды, типа дня
js/calendar.js           даты, месяцы, ячейки сетки
js/entry.js              редактор записи дня, автосохранение
js/settings.js           настройки, палитра, копии
js/app.js                состояние, навигация, отрисовка календаря
icons/                   иконки для экрана «Домой»
tools/make_icons.py      скрипт, которым сгенерированы иконки
```

## Обновление после правок

Кэш сервис-воркера версионный. После изменения любого файла подними версию в `service-worker.js`:

```js
var CACHE = 'mood-diary-v2';
```

Иначе на устройстве останется старая версия.
