# Личный тренажёр

Статический сайт для GitHub Pages. Материалы лежат в `bundle.enc.json` в зашифрованном виде (AES-256-GCM, ключ из пароля через PBKDF2) и расшифровываются в браузере только после ввода пароля.

Пароль в репозитории не хранится. Если включить «Запомнить на этом устройстве», ключ сохраняется в браузере; чтобы забыть его, очисти данные сайта в браузере.
